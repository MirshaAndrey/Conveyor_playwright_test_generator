# Conveyor

**Conveyor** — это легковесный CLI-инструмент на языке Go для автоматической генерации E2E-тестов (Playwright + TypeScript) с использованием локальных LLM через [Ollama](https://ollama.ai/).

Conveyor позволяет автоматизаторам тестирования быстро переводить текстовые чек-листы и тест-кейсы в готовый к выполнению, надежный код проверок.

##  Особенности

*   **Локальная генерация**: Вся работа происходит на вашем железе через Ollama. Никаких утечек данных в облако.
*   **Два режима работы**:
    *   *Интерактивный / Одиночный*: ввод тест-кейса вручную и стриминг ответа в консоль.
    *   *Пакетный (Batch)*: подача списка тест-кейсов из файла и красивая генерация с in-place прогресс-баром.
*   **Playwright Ready**: Встроенный системный промпт настроен на жесткие стандарты: только валидный TypeScript, использование `test.describe`, правильные селекторы (`getByTestId`, `getByRole`) и обязательные `expect`.
*   **Умное сохранение**: Автоматическая генерация slug-имён для файлов (например, `2026-03-29_15-04-05_poisk_tovara.ts`) с поддержкой умной транслитерации кириллицы.

##  Установка

Убедитесь, что у вас установлены [Go](https://go.dev/) (1.23+) и [Ollama](https://ollama.ai/).

```bash
# Клонирование репозитория
git clone https://github.com/mirshaandrey/conveyor.git
cd conveyor

# Сборка проекта для вашей текущей операционной системы
go build -o conveyor .

# Кросс-компиляция (создание бинарников для других ОС)
# Для Windows
GOOS=windows GOARCH=amd64 go build -o conveyor.exe .

# Для Linux
GOOS=linux GOARCH=amd64 go build -o conveyor-linux .

# Для macOS (Intel)
GOOS=darwin GOARCH=amd64 go build -o conveyor-mac .

# Для macOS (Apple Silicon - M1/M2/M3)
GOOS=darwin GOARCH=arm64 go build -o conveyor-mac-arm .
```

Обязательно запустите сервер Ollama и скачайте нужную модель (рекомендуются coder-модели, например `qwen2.5-coder:7b` или `qwen3-coder:30b`):

```bash
ollama run qwen2.5-coder:7b
```

##  Использование

### Запуск интерактивного режима
Просто запустите программу без аргументов. Она спросит, какую модель использовать, и перейдет в режим ожидания ввода тест-кейсов.

```bash
./conveyor.exe
```

### Одиночный тест-кейс (через аргумент)
```bash
./conveyor.exe -task "Авторизация с неверным паролем: ожидается сообщение об ошибке" -model "qwen2.5-coder:7b"
```

### Пакетный режим
Создайте текстовый файл (например, `cases.txt`), где на каждой строке описан шаг или тест-кейс, и запустите:

```bash
./conveyor.exe -tasks-file cases.txt
```

### Доступные флаги

| Флаг | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `-task` | `""` | Текст одиночного тест-кейса для генерации. |
| `-tasks-file` | `""` | Путь к файлу со списком задач (одна задача на строку). |
| `-model` | `mistral-small3.2:latest` | Имя локальной модели Ollama для использования. |
| `-out` | `""` | Конкретный путь для сохранения результата (работает для одиночного запуска). |
| `-no-save` | `false` | Отключить автоматическое сохранение файлов в папку `TestCasesTS/`. |
| `-url` | `http://localhost:11434` | URL вашего сервера Ollama. |

##  Структура проекта

*   `main.go` — инициализация CLI флагов, базовые проверки и старт основного цикла работы.
*   `ollama.go` — конфигурация запросов к API Ollama, логика стриминга и работы с моделями. Вшит системный промпт для Playwright.
*   `tracker.go` — потокобезопасная in-place реализация UI-трекера прогресса в терминале.
*   `batch.go` — логика обработки пакета заданий из файла.
*   `files.go` — утилиты для работы с ФС: формирование слагов, транслит, чтение/запись.
